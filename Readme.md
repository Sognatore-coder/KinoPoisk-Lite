# Кинопоиск Lite 🎬

Мини-приложение для удобного поиска и фильтрации фильмов с использованием асинхронной загрузки данных.

## ✨ Особенности проекта
* **Асинхронная загрузка:** Динамическое получение данных о фильмах.
* **Гибкая фильтрация:** Сортировка по жанрам, рейтингу и другим параметрам.
* **Хранилище данных:** Локальное управление состоянием (storage) и ведение статистики.

## 📁 Структура проекта
* `css/style.css` — Стили интерфейса.
* `js/app.js` — Точка входа и инициализация приложения.
* `js/dataLayer.js` — Работа с API и сетевыми запросами.
* `js/renderLayer.js` — Отображение контента на странице.
* `js/filters.js` — Логика фильтрации и поиска.
* `js/stats.js` — Сбор и аналитика данных.
* `js/storage.js` — Локальное сохранение данных (LocalStorage).

## 🚀 Запуск проекта
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Sognatore-coder/KinoPoisk-Lite.git
   ```
2. Откройте файл `index.html` в вашем браузере.
